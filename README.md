# Text Converter Project

## Descripción

Este es un proyecto personal desarrollado en Python que consiste en un conversor de texto interactivo. El usuario puede ingresar un texto y elegir una de las siguientes acciones para realizar sobre dicho texto:

1. Convertir el texto a **mayúsculas**
2. Convertir el texto a **minúsculas**
3. **Capitalizar** el texto (poner la primera letra en mayúscula)
4. Contar la cantidad de **vocales y consonantes**

 

El programa ejecuta la acción seleccionada y muestra el resultado correspondiente.

## Características

- Interfaz interactiva basada en la línea de comandos.
- Funciones para modificar y analizar texto.
- Validación de entrada del usuario para garantizar una experiencia fluida.

## Tecnologías Utilizadas

- **Python 3.8 o superior**

## Cómo Ejecutar el Proyecto

1. Clona el repositorio desde GitHub:
   ```bash
   git clone https://github.com/ITSULI19/conversor-de-texto.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd conversor_texto
   ```
3. Ejecuta el archivo principal:
   ```bash
   python conversor_texto.py
   ```

## Uso

1. Ingresa un texto cuando el programa lo solicite.
2. Elige una de las opciones del menú para realizar la acción deseada.
3. Observa el resultado en la terminal.

## Ejemplo de Menú

```
Ingrese una cadena: Hola Mundo
Seleccione una opción:
1. Convertir a mayúsculas
2. Convertir a minúsculas
3. Capitalizar
4. Contar vocales y consonantes
5. salir
Opción: 1
Resultado: HOLA MUNDO
```
